# Курс New Relic для начинающих

Личный учебный материал. Не коммитится: папка `_personal/` исключена через `.git/info/exclude`.

Факты проверены по документации New Relic 15.11.2026. Интерфейс и условия бесплатного тарифа меняются. Перед важным шагом сверяйтесь со ссылками в конце каждого урока.

## Маршрут курса

                                                  │

                                        алерт, расход

## Как проходить курс

Читайте уроки по порядку. Уроки 1–4 общие и годятся для любого приложения. Урок 5 и дальше привязаны к GitHubBackup.

Важное условие. Ключ конфигурации `OpenTelemetry:Headers` появится в GitHubBackup только после issue #101. Пока его нет в коде, урок 5 описывает будущую настройку.
