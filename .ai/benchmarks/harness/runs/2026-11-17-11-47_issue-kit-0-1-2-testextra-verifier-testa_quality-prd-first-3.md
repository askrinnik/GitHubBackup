Опцию `--since <date>` нельзя добавить только в CLI. В коде нет даты последнего push (`PushedAt` не найден). Фильтр `BackupRunFilter` сегодня знает только аккаунт и репозиторий, а `Includes(BackupWorkItem)` решает по именам. Нужны четыре изменения: PRD, модель GitHub, оркестратор и разбор аргументов.

По правилам репозитория сначала идёт PRD. `.claude/rules/cli.md` говорит: новая опция — это сначала изменение PRD. Поэтому код я начну только после вашего одобрения PRD.

## Вопросы, которые нужно решить в PRD

- **Часовой пояс.** Дата без времени. Я предлагаю считать её началом дня по локальному времени и включать границу.
- **Обнаружение.** Предлагаю оставить его как есть. Тогда решения о новых, пропавших и переименованных репозиториях остаются корректными. `--since` отсекает только обработку (клон, архив).
- **Новый репозиторий с push раньше даты.** Добавить в конфигурацию без бэкапа, или пропустить совсем?
- **Репозиторий недоступен (`Unavailable`) или нет `PushedAt`.** Я предлагаю не фильтровать его, чтобы не скрыть сбой.
- **`--since` вместе с `--repo`.** Либо запретить сочетание, либо разрешить.
- **Расход запросов к API.** Для отдельных записей конфигурации нужен один запрос на репозиторий.
- **Статус пропущенных** в сводке и истории запусков. Если это новый статус, его нужно добавить в FR-9.8.

## Важное ограничение

`pushed_at` меняется только при push. Если репозиторий изменился другим способом, например удалением тега через API, а его последний push был раньше даты, этот запуск его пропустит. Это нужно записать в PRD.
