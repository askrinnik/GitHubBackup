## Шаг 2. Решения, которые нужно принять до кода

У каждого пункта есть моя рекомендация.

1. **Какая дата сравнивается.** Рекомендую `pushed_at` из GitHub API. Это та же информация, что приходит при обнаружении, поэтому лишних запросов не будет.
2. **Формат даты.** Рекомендую ISO 8601. Дата без времени означает 00:00 UTC. Неверная дата даёт код `2` (FR-9.10).
3. **Связь с `--repo`.** Для `--repo` обнаружения нет (FR-2.7), и `pushed_at` пришлось бы запрашивать отдельно. Рекомендую запретить сочетание `--since` и `--repo`, как уже запрещено `--account` вместе с `--repo`.
4. **Обнаружение.** Оно должно видеть полный список репозиториев. Иначе репозитории, отфильтрованные по дате, ошибочно получат статус `Unavailable` (FR-2.4). Поэтому фильтр применяется после обнаружения и до клонирования.
5. **Статус отфильтрованных.** Нужно решить, получают ли они статус `Skipped` и как учитываются в сводке и коде возврата (FR-9.8, FR-9.10). Рекомендую статус `Skipped` без влияния на код возврата.
6. **Репозиторий без `pushed_at`** (пустой). Рекомендую пропускать.
7. **Wiki.** Пуши в wiki не меняют `pushed_at`. Рекомендую пропускать wiki вместе с репозиторием и записать это в PRD как ограничение.
8. **`--dry-run` и `--silent`.** Фильтр действует одинаково в обоих режимах. Рекомендую так и оставить.
9. **Приложение WPF.** Параметр только для консоли, а UI остаётся без изменений. Это нужно подтвердить, потому что FR-12.7 требует одну логику для обоих хостов. Поэтому сам фильтр лежит в `Core`.
