## Вопросы, которые нужно решить до PRD

1. **Что значит «pushed to».** Дата `pushed_at` из GitHub API — это самый простой вариант. Она не учитывает push в другие ветки и теги отдельно от остального. Для режима «только изменившиеся» в программе уже есть быстрая проверка по `ls-remote`. `--since` её не заменяет.
2. **Формат и часовой пояс.** Предлагаю `yyyy-MM-dd` в локальном часовом поясе (через `TimeProvider`). Нужно ли принимать полное время с зоной?
3. **Что делать с репозиторием без `pushed_at`** (пустой репозиторий). Предлагаю пропускать его.
4. **Как фильтр работает с `--repo`.** Тот репозиторий обнаружения не проходит. Предлагаю применять `--since` и к нему. Это ещё нужно зафиксировать в PRD.
5. **Что с обнаружением (FR-2.7).** Обнаружение идёт на каждом запуске. Предлагаю не отключать его при `--since`, а фильтровать только обработку.
6. **Статус и отчёт.** Нужен ли отдельный статус «пропущен по `--since`» в сводке и истории SQLite? Если да, это затронет модель истории и, возможно, миграцию EF.
